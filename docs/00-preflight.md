# 00 准备阶段

## 1. 记录 iKuai 现有配置

替换之前先把这些信息抄下来（截图 + 文字都行），后面在 OpenWrt 里要照着填：

| 项目 | 记什么 |
| --- | --- |
| 宽带账号 | PPPoE 用户名 / 密码 |
| VLAN | 光猫是否需要 VLAN（常见 41），iKuai 的 WAN 里能看到 |
| MTU | iKuai 里 WAN 的 MTU（一般 1492） |
| LAN 网段 | iKuai 的 LAN IP 和 DHCP 池 |
| 静态绑定 | iKuai 的 DHCP 静态分配表（MAC ↔ IP ↔ 备注） |
| 端口转发 | 有哪些映射（外网端口 → 内网 IP:端口） |
| DDNS | 服务商、域名、账号/Token |
| WoL | 有没有在 iKuai 上做过网络唤醒 |
| IPv6 | iKuai 是否开了 IPv6、前缀长度 |

> 静态绑定表最好直接导出或截图，OpenWrt 里要一条条重新建。

## 2. 让 RA81 临时联网（用于装软件）

装软件必须先有外网。做法：

1. RA81 **先不要**接光猫
2. 把 RA81 的 **WAN 口**用网线接到 iKuai 的 **LAN 口**
3. 电脑连 RA81 的 LAN 口，打开 `http://192.168.1.1`（当前还是出厂 LAN IP）
4. **网络 → 接口** 里 WAN 应该是 DHCP 客户端，确认能拿到 iKuai 下发的地址
5. 状态 → 概览里看到 WAN 有 IP、能上网即可

### 注意事项

- 如果 iKuai 的 LAN 也是 `192.168.1.0/24`，会冲突：先把 RA81 的 LAN 临时改成
  `192.168.9.1` 之类的地址再接线，装完软件、开始离线配置时再改成 `10.10.10.1`。
- 这时 RA81 是“二级路由”，能上网但还在 NAT 后面，只用来装包，不影响 iKuai。

## 3. 检查时间

```sh
date
```

时间不对会影响 https 下载。可以在 **系统 → 系统 → 时间同步** 里确认 NTP 已启用。

## 4. 先做一次备份

**系统 → 备份/升级 → 生成备份**，下载到电脑。

这是“出厂 + 联网可用”的状态，后面出问题可以回到这里。
