# 09 替换上线与回滚

前提：软件已装齐（[01](01-packages.md)），离线配置已完成（[02](02-lan-ip.md)–[08](08-backup-restore.md)），
并且做过一次备份。

## 替换步骤

1. **记录 iKuai 的接线**（哪根是光猫/入户线，哪根去交换机/AP），拍照
2. 断开 iKuai 电源（先不要恢复出厂）
3. 把**光猫/入户线**插到 RA81 的 **WAN 口**
4. 把原来接 iKuai LAN 的交换机/AP 网线，插到 RA81 的 **LAN1–LAN3**
5. RA81 上电，等 1–2 分钟

## 上电后验证（按顺序）

在电脑上（应拿到 `10.10.10.x`）：

1. 打开 `http://10.10.10.1` 能进管理页
2. **状态 → 概览**：WAN 有 IPv4 地址（PPPoE 拨号成功）
3. 能上网：打开任意网站
4. 能解析域名：`nslookup www.baidu.com`
5. IPv6：**状态 → 概览** 有 IPv6 地址；客户端 `ip -6 addr` 有 `240e:`/`2408:` 地址
6. DDNS：服务 → 动态 DNS 里日志显示更新成功；外部 `nslookup 你的域名 8.8.8.8`
7. 静态绑定：固定设备拿到 `10.10.10.2–99` 的地址
8. 网络唤醒：在 **网络 → Wake-on-LAN** 里点一次，目标机应开机

## PPPoE 拨不上怎么办

按可能性排查：

| 现象 | 处理 |
| --- | --- |
| 一直 connecting | 账号密码错；或需要 VLAN（回 iKuai 看 WAN 的 VLAN ID，在 RA81 建 `wan.<vid>`） |
| 有 IP 但打不开网页 | DNS 问题：WAN 高级设置里手动填 DNS，或检查 LAN 的 DHCP 选项 6 |
| 大包不通（能 ping 小包） | MTU 降到 1480 试 |

## 回滚

任何一步卡住、短时间内搞不定：

1. RA81 断电
2. 把光猫线插回 iKuai，恢复原来的接线
3. iKuai 上电（配置一直没动，立即可用）

所以 iKuai 在 RA81 完全验证通过之前不要动配置、不要恢复出厂。

## 收尾

- 再生成一次备份并下载到电脑
- 在 README 或这里记录最终信息：PPPoE 账号、VLAN、DDNS 域名、固定 IP 分配表
- 旧 iKuai 可以先留着当备用，确认稳定一两周后再决定处理
