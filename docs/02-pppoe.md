# 02 PPPoE 拨号

## 网页操作

1. **网络 → 接口**，找到 `WAN`，点 **编辑**
2. **常规设置**：
   - 协议：`PPPoE`
   - 用户名 / 密码：宽带账号（运营商给的）
   - 服务名、AC 名称：留空（除非运营商明确要求）
3. **高级设置**：

| 选项 | 值 |
| --- | --- |
| 使用对端提供的 DNS | 勾（一般） |
| MTU | `1492`（PPPoE 标准） |
| 保持连接 | 勾上 |
| LCP 回显间隔 | 默认 `5` |
| 强制链路 | 勾上 |

4. **防火墙设置**：区域选 `wan`
5. **保存并应用**

## 需要 VLAN 的情况

很多地区的光猫桥接后，PPPoE 要走 VLAN（常见 41、还有就是 41/…）。
如果直接拨号一直失败：

1. **网络 → 接口 → 设备** → **添加设备配置**
2. 类型：VLAN（802.1q），基础设备选 `wan`，VLAN ID 填运营商给的（例如 `41`）
3. 回到 WAN 的“设备”选项，选刚建的 `wan.41`

> RA81 用的是 DSA，WAN 口在设备列表里就是 `wan`。

## 验证

```sh
ip addr show pppoe-wan          # 应看到 inet 100.x / 公网地址
ip route | head                 # 应有一条 default dev pppoe-wan
ping -c3 223.5.5.5
nslookup www.baidu.com
```

网页上：**状态 → 概览** 的 WAN 一栏应显示已获取到的 IPv4 地址。

## 排查

| 现象 | 可能原因 |
| --- | --- |
| 一直“正在连接” | 账号密码错、光猫没桥接、需要 VLAN |
| 有 IP 但上不了网 | DNS 没下发，手动在 WAN 的“高级设置”里加 DNS |
| 网速异常慢 / 大包丢 | MTU 不对，试 1480 / 1492 |
| 频繁掉线 | LCP 回显间隔太短或被运营商限制，调大或关“强制链路” |
