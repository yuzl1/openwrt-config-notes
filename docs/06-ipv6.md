# 06 开启 IPv6

> 离线配置阶段把 WAN6/LAN 的选项设好即可，地址要等[替换上线](09-cutover.md)、
> PPPoE 拨号成功之后才会下发。

## 前提

- 运营商支持 IPv6（PPPoE 一般会给 IPv6 前缀 PD）
- 光猫是桥接模式，由路由器拨号

## 检查当前状态

```sh
ip -6 addr
ip -6 route
```

如果只有 `fe80::` 链路本地地址，说明还没拿到 IPv6。

## 网页配置

### 1. WAN6

**网络 → 接口 → WAN6 → 编辑**

| 选项 | 值 |
| --- | --- |
| 协议 | DHCPv6 客户端 |
| 请求 IPv6 地址 | `try`（或 `force`） |
| 请求 IPv6 前缀长度 | `auto` 或 `56`（看运营商） |
| 禁用对端通告的默认路由 | 不勾 |

### 2. LAN

**网络 → 接口 → LAN → 编辑 → DHCP 服务器 → IPv6 设置**

| 选项 | 值 |
| --- | --- |
| 指定的 DHCPv6 服务 | 服务器模式 |
| RA 服务 | 服务器模式 |
| DHCPv6 模式 | 有状态 + 无状态（或按需） |
| IPv6 分配长度 | `64` |

保存并应用后，客户端会拿到 `240e:` / `2408:` 开头的公网 IPv6。

### 3. 防火墙

**网络 → 防火墙 → 常规设置**，确认：

- `wan` 区域：允许 `ICMPv6` 入站、允许 `DHCPv6` 客户端
- `lan` 区域：允许 `DHCPv6`、`RA` 入站

如果之后要从外网访问内网 IPv6 服务，在 **防火墙 → 通信规则** 里单独放行端口，
不要整个关闭防火墙。

## 验证

```sh
ip -6 addr show br-lan | grep global
ip -6 route | head
ping6 -c3 2400:3200::1
```

客户端上：

```sh
ip -6 addr          # 有 240e: 开头地址
curl -6 https://ipv6.ip.sb
```

## 常见问题

| 现象 | 排查 |
| --- | --- |
| 拿不到 IPv6 地址 | 光猫没桥接 / 运营商没开 IPv6 / 需要 VLAN |
| 有地址但上不了 IPv6 网站 | 防火墙 ICMPv6 被拦，或 DNS 没解析 AAAA |
| 只有路由器有、客户端没有 | LAN 的 RA/DHCPv6 没开，或分配长度不是 64 |
| 前缀会变 | 运营商 PD 会续租，DDNS 请用 IPv6 的条目 |
